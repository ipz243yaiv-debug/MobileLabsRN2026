*1. Інструкцію запуску:*

1) Створення проекту на WebStorm;
   
2) Встановлення бібліотек: npx expo install onesignal-expo-plugin;  npm install --save react-native-onesignal
 
3) Запуск серверу командою: npx expo start
 
4) Запуск програми через Android studio командою npx expo run:android

*2. Опис реалізованого функціоналу:*

У межах виконання лабораторної роботи було створено мобільний застосунок "To-Do Reminder" на базі React Native та Expo. 
Основна логіка базується на створенні завдань із заголовком та описом, які зберігаються в локальному стані додатка та відображаються через FlatList. 
Головною особливістю є інтеграція з сервісом OneSignal для планування відкладених сповіщень. 
Реалізовано кастомний механізм вибору дати та часу: оскільки Android не підтримує одночасний вибір обох параметрів, додаток спочатку викликає календар, 
а після підтвердження дати автоматично відкриває годинник. Кожне створене завдання автоматично реєструється на сервері OneSignal із затримкою відправки. 
Також реалізовано функцію синхронного видалення: при вилученні картки зі списку в додатку, відправляється запит на видалення відповідної нотифікації з черги OneSignal.

*4. Висновки:*

Що таке push-сповіщення і як воно працює?
Це повідомлення від сервера, які приходять на пристрій навіть при закритому додатку завдяки унікальним токенам реєстрації. 
Система працює через хмарну службу, яка «проштовхує» дані на девайс, щойно сервер ініціює відправку.

Яка роль Firebase Cloud Messaging у потоці надсилання повідомлень?
FCM виступає посередником-транспортом, який відповідає за безпосередню доставку повідомлення на Android-пристрій. 
Він підтримує стабільний зв'язок із гаджетом та керує чергою відправки, якщо пристрій тимчасово перебуває поза мережею.

Як запланувати та скасувати сповіщення через OneSignal API?
Для планування надсилається POST запит із параметром send_after, де вказується час у форматі ISO 8601. 
Скасування реалізується через DELETE запит із використанням ідентифікатора повідомлення, отриманого під час його створення.

Як обробляти push-сповіщення, коли застосунок відкрито (foreground)?
У коді використовується слухач подій foregroundWillDisplay, який дозволяє перехопити вхідне сповіщення. 
Це дає можливість розробнику оновити дані в додатку або примусово відобразити системний банер за допомогою методу notification.display().
